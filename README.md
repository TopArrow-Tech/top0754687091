## What changed from the parent version

- 主线关卡从 8 关扩到 16 关，分成四个章节，选关页一眼能看到每关的地图形状、目标和步数。
- 每关都有不一样的棋盘轮廓，中间会出现缺口，糖果只会在连通的位置下落。
- 每张关卡卡片上标了难度系数和 2 星、3 星分数线，打之前就能估一估压力。
- 新增动画版计分说明，用糖果演示三连得分、连锁加倍、四连生成条纹糖和特殊糖奖励。
- 第一次进入会自动播放玩法指南动画，之后也能从首页再看。
- 提示的糖果现在有醒目的描边和交换箭头，走错一步会告诉你为什么没消除。
