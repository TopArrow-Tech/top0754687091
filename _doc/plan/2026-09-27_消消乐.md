# 消消乐

## 背景

按顶箭 basic 约定做一个单机消消乐。小游戏用 Node，不部署到服务器，页面资源全部放在应用里。

## 目标

- 8×8 棋盘，交换相邻糖果形成三连，掉落后可以连锁。
- 四连条纹、五连彩虹、T/L 包装糖；后几关有冰块。
- 8 个关卡，步数有限，按目标和分数给 1 到 3 星。
- 中英文可切换，选择记在 SQLite 里。
- 对局区域禁止右键菜单，避免误点弹出浏览器菜单。

## 技术方案

- `server.js` 只监听 `127.0.0.1`。`GET /__health` 返回 200。静态文件只从 `public/` 提供。
- 进度表 `level_progress` 存最高分、星数、是否通关。`meta` 存 `unlocked` 和 `lang`。只有当前已解锁的关卡通关后才解锁下一关。
- `public/js/rules.js` 不碰 DOM，测试用平台自带的 Node 跑 `test/rules.test.js`。
- 界面用 DOM 和 CSS 做交换、消除和掉落。语言包在 `public/js/i18n.js`。第一次打开看浏览器语言，玩家改过之后以存档为准。
- 棋盘和提示条监听 `contextmenu` 并取消默认行为。右键和中键不参与选格或交换。

## 涉及文件

- `manifest.json`、`server.js`、`lib/db.js`
- `public/` 下的页面、样式和脚本
- `test/rules.test.js`、`test/db.test.js`

## 注意事项

- 冰块盖在糖果上，自己不能凑成三连；旁边的消除或条纹、包装、彩虹打到它才减耐久。耐久归零后这颗糖才变成普通糖，同一次打击不会把它直接消掉。
- 横着的四连生成竖条纹（消除时清一列），竖着的四连生成横条纹。
- 不要引用外网字体、图片或脚本。
