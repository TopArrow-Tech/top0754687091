# 2026-09-29

画面和音效向连连看靠拢：明亮、有边距、交互有声音。

## 背景

原先对局页是深棕色，棋盘用 `100cqh` 撑满窗口高度。浏览器 Ctrl- 缩小页面时，视口的 CSS 像素变多，8×8 棋盘跟着拉高，看起来不像整幅画面在缩放。音效只有很轻的合成音，也没有开关。

## 改动

- 背景改成天蓝 / 糖果粉 / 浅黄；首页、选关用浅色卡片；棋盘格子改成带厚度的白底糖块。
- 六种糖果和彩虹糖改成本地 SVG（`public/assets/`）。
- 棋盘最大边长约 528px，按窗口剩余空间缩小、不再随视口长高。缩小浏览器页面时，棋盘保持设计尺寸，四周留出明亮背景。
- `public/js/audio.js` 用 Web Audio 合成点击、交换、消除、连锁、冰块、提示、重排、过关/失败；首页和对局可静音（记在 localStorage）。

- `public/css/game.css`、`public/js/view.js`、`public/js/main.js`、`public/js/audio.js`、`public/js/i18n.js`
- `public/assets/*.svg`、`public/favicon.svg`
